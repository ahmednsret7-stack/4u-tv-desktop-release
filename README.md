# 4U TV — Windows

هذا المستودع يحمل ملف عنوان خادم التحكم فقط، ولا يحتوي سورس التطبيق.

المثبت ملف EXE واحد لويندوز 10 و11 بنظام 64 بت، حجمه نحو 26.4 ميغابايت. يُحفظ في App Storage ويُنزل من الموقع الرسمي عبر المسار /api/downloads/4u-tv-windows.exe بعد نشر الموقع.

يوضع أصل عنوان الموقع المنشور في server.json بعد النشر. لا تعمل النسخة قبل ربط الخادم وموافقة المالك، ولا يتأثر أندرويد بهذا التحكم.

السورس محفوظ في مستودع خاص. استمرار الخدمة يحتاج استضافة فعّالة؛ لا يوجد ضمان استضافة مدى الحياة.
